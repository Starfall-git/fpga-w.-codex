# V0.21 手动 / 自动调光

打开“曝光 / 算法调节”：
- 点击“手动调光”，将当前三个滑块值写入摄像头，关闭自动曝光、自动模拟增益、自动数字增益。之后数值保持，直到再次调参或切换模式。
- 手动模式下拖动滑块或点击后使用左右方向键，都不会重新开启自动调光。
- 点击“自动调光”，立即发送恢复上电自动配置的命令，重新启动曝光调整，然后持续适应环境。收敛需要摄像头运行若干帧，并非按钮返回时已完成。
- 自动模式下滑块仍可临时调参，完成后自动接管；要固定设置请先点击手动调光。
