# V0.13：以用户恢复版本为基线保留轮廓

V0.12已被用户撤回，其56～60项代表失败的历史尝试，不是本版生效行为。
上次从柔和梯度输出改为二值化，使弱轮廓直接消失，超过阈值的噪点则被提升到白色；
同时把中心亮度作为灰度扣减下限，进一步压暗亮区域的低对比轮廓。
这些设计选择不符合用户希望保留原有柔和完整轮廓的目标。RTL仿真通过只代表实现符合公式，不能证明画质改善。

## 新增降噪公式

对窗口中心c和八个邻点n：差值绝对值不超过8时采用n，否则用c替代。

```text
mean = (8*c + sum(8个选中的邻点) + 8) >> 4
refined = c + clamp(mean-c, -2, +2)
```

中心占一半权重，避免简单平均过度模糊；较大亮度变化不跨边缘混合。
原来的孤立点替换条件满足时，优先输出中值；新增处理不改变其判定。
参数在video_median3x3中：REFINE_NOISE=1、NOISE_DELTA=8、MAX_CORRECTION=2。
REFINE_NOISE=0可精确恢复旧选择性中值；这三个都是编译参数，需要重新编译bit。
不要把MAX_CORRECTION直接调大来追求干净背景，低对比细节同样可能受损。

这是一层保守降噪，不是完整双边滤波、时域去噪或阴影分离。
小于等于8级的真实细节也可能轻微变暗；在本测试下未改变20级台阶和16级细线，不代表所有真实文字完全不变。
大尺度照明波纹、曝光条纹、物体真实纹理仍可能产生梯度。
照片经过显示器和手机拍摄，不能单靠照片定量区分摩尔纹与FPGA输出噪声。
