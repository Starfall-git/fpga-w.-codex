# V0.16 高斯降噪、Scharr 与流式 Canny 使用说明

## 使用和切换

下载 `outflow/Ti60_AR0135_v016_gaussian_scharr_canny.bit`，并用同一工程的 `python -m host.gui` 启动新版控制台。串口仍只发送命令和状态；图像从 HDMI 输出。旧 GUI 不认识扩展状态保留字节，应与新 bit 一起更新。

所有新增功能复位默认关闭，默认显示原图。点击开关即发送，在场消隐应用。Sobel、Scharr、Canny 三者互斥，也可全部关闭。中值滤波与高斯独立选择，启用 Canny 会自动启用高斯；若要完全关闭 Canny 和平滑，请分别关闭 Canny、高斯。保边降噪只在高斯生效时起作用。

- **高斯滤波**：3×3 核 `[1,2,1; 2,4,2; 1,2,1]/16`，加8后右移4位四舍五入，主要平滑局部细密亮度波动。
- **保边降噪**：高斯的可选灰度差门控。邻居与中心相差超过16时用中心代替该邻居，减少跨强轮廓平滑。它是轻量保边近似，不是完整双边滤波；强噪点也可能被当作边缘保留，遇此情况可组合现有选择性中值，或关闭保边比较。
- **Scharr**：使用3/10/3水平和垂直梯度，幅度按 `(abs(Gx)+abs(Gy))>>2` 归一化。保留灰度边缘强弱，输出为 `min(max(幅度-阈值,0)/2,255)`，并支持反相；不把原 Sobel 改成硬二值。
- **Canny（两轮连接）**：高斯→Scharr梯度→四方向非极大值抑制→双阈值→两轮8邻域弱边缘连接，最终二值输出。高阈值为输入值（最小1），低阈值为一半（最小1）。只保留强边缘及两轮内被强边缘连接到的弱边缘。

**限制必须区分：**此版本是有限两轮连接的实时 Canny 变体，不是整帧递归滞后追踪；很长的弱边缘链仍可能断裂。标准 Canny 的说明见 [OpenCV 官方文档](https://docs.opencv.org/4.12.0/d7/de1/tutorial_js_canny.html)。Scharr/高斯参考 [OpenCV 滤波与梯度接口](https://docs.opencv.org/4.0.1/d4/d86/group__imgproc__filter.html)。

## 如何调试成像

先关闭所有新增功能确认原图及旧 Sobel，再打开高斯+Scharr比较同一固定场景，最后比较 Canny。阈值回车提交，三种边缘算法共用数值，但最佳阈值不能直接等同：旧 Sobel还有原自适应逻辑，Scharr/Canny使用上述新定义。可先用80作试验起点（不是上板标定值），断裂时下调，背景边缘过多时上调。比较时固定曝光、光照、距离、缩放和场景。

细密随机噪声与真实纹理都可能产生梯度；高斯可减少局部波动，但会削弱细小文字和弱轮廓。宽范围光影、条纹或照明频闪不保证由3×3滤波消除，需要结合原图检查曝光/增益和照明。保边模式也不是强度越大越好。未在你的摄像头上验证前，不承诺噪点全部消失或轮廓完全不断。

高斯单独启用时输出处理后的灰度；全关闭时原 RGB 路径保持。AR0135 继续使用 `ENABLE_GRAY=0` 的原亮度提取，未重写灰度及旧 Sobel 算法。DDR冻结、回放、对比依旧保存源图，并经过当前ISP；改变算法可以比较同一个DDR冻结源帧。

数据链：Gray(3拍)→中值/旁路(5拍)→高斯/旁路(3拍)→边缘窗口(2拍)→Canny(11拍)。Scharr和Sobel本身3拍，另补8拍。原图、中值和高斯输出分别补齐24、16、13拍，总输出统一24拍，HS/VS/DE与数据同拍。相比原13拍增加11个像素时钟；新功能关闭时原像素值不变。

窗口使用过去两行构建因果3×3窗口，有空间中心位移与无效边界；24拍指寄存器同步延迟，并不意味着所有算法的空间坐标无偏移。Canny因多级窗口，上/左无效区域大于Sobel（当前默认配置前14行/列），其余区域不通过补零参与卷积。以后添加分模块，要同时计算数据/有效位/HS/VS/DE延迟与窗口边界，并补齐所有旁路；不可只延迟DE。

CMD 0x11 的模式字节：bit0 Sobel，bit1 反相，bit2 中值，bit3 高斯，bit4 Scharr，bit5 Canny，bit6 保边；bit7保留0。bit0/4/5只可单选，硬件拒绝冲突；Canny请求会强制bit3=1，应答返回实际值。标准应答payload[6]=0x0F标记高级ISP支持，payload[7]=0。CMD 0x12“默认”清除全部模式，保留阈值与DDR已存帧，返回直播。
