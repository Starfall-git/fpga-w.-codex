# V0.9 中值滤波独立开关

## 运行方式

GUI 的“中值滤波”按钮点击即发送串口命令，无需另点应用。Sobel 与中值滤波互不依赖：

| 中值滤波 | Sobel | HDMI 输出 |
| --- | --- | --- |
| 关 | 关 | 原始 RGB 图像（默认） |
| 开 | 关 | 3×3 中值滤波后的灰度图 |
| 关 | 开 | 原灰度图的 Sobel 黑白边缘 |
| 开 | 开 | 中值滤波后再做 Sobel |

“黑白反转”仍只对 Sobel 边缘输出生效。“默认”命令关闭中值滤波、Sobel 与黑白反转，恢复几何变换默认值，保留现有 Sobel 阈值。连接不支持新功能的旧 bit 时，GUI 会禁用中值滤波按钮。

## RTL 与协议

`video_processing.v` 新增 `ENABLE_MEDIAN` 输入，与已有 `ENABLE_SOBEL`、`BINARY_OUTPUT` 并列。灰度 1 拍、中值前窗口 2 拍、中值计算 3 拍、Sobel 前窗口 2 拍、Sobel 3 拍，共 11 拍。原始 RGB 延迟 11 拍，中值输出延迟 5 拍；四种模式统一使用末级 Sobel 的 HS/VS/DE。这可避免切换开关时 HDMI 同步突然跳拍。原图旁路保留 RGB 通道颜色。

中值开关在 Sobel 第二窗口的输入处选择中值结果或同拍的原始灰度。因此开关由 `threshold_cdc` 在像素时钟域的场消隐应用，串口成功应答携带实际生效的模式。对图像处理中任何新模块，都应同时核对像素、HS、VS、DE 的总延迟及上游行缓存的跨帧有效区。

现有 13 字节串口帧和命令 `0x11` 不变。请求 DATA0：bit0=Sobel，bit1=黑白反转，bit2=中值滤波；其余位必须为零。状态应答 DATA4 的能力位 bit7 表示支持中值滤波，DATA5 bit2 回读已生效的中值状态。`0x12` 默认命令清除三个模式位并保留阈值。旧 bit 的能力位 bit7 为零，上位机不会发送中值开启请求。
